1Purpose & scope

This UAT validates the pertussis-specific functionality of EpyScenario and the contact-intervention planner from the user's perspective — confirming each capability behaves as specified before sign-off. It covers positive cases (the feature works as intended) and negative cases (invalid input is rejected safely).

2Environment & prerequisites

  1. Launch the application. In the project folder run ./run_dashboard.ps1, then open http://localhost:8501. The launcher restarts the app automatically if it exits.
  2. Use a fresh browser session for a clean starting state. If a run has locked the workspace, click Start new session to change model/geography.
  3. Recommended test data: Model = SEIRS (Pertussis); Geography = a Lane County, Oregon entry.
  4. If a page looks stale after a restart, hard-refresh with Ctrl+Shift+R.

3How to run a test

  1. Read the Preconditions, then perform the Steps in order.
  2. Compare what you observe to the Expected result.
  3. Record Pass or Fail in the tracking sheet, with a one-line Actual result.
  4. Capture a before and after screenshot for evidence (Windows: Win+Shift+S).
  5. For a Fail, note the severity and any error text shown.
Reference results. Each test below shows the result from an automated dry run. Treat these as a baseline — the UAT team should independently re-verify and record their own Pass/Fail. One known finding (I-04) is documented in the tracking sheet.
